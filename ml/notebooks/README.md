# Notebooks Khám phá Dữ liệu (`ml/notebooks/`)

> Thư mục dành riêng cho notebook khám phá dữ liệu (`yield_samples`, tập `synthetic` từ `tools.simulator synth-yield`, phân tích phân bố vùng khí hậu, phần dư theo cây trồng) — **không** dùng trong pipeline huấn luyện hoặc suy luận chính (`ml/train.py`, `worker/inference.py`).

- Để chạy notebook cục bộ, cài môi trường từ `ml/requirements.txt` và đặt `PYTHONPATH=platform;.`.
- Tài liệu đặc tả pipeline AI/ML chính thức xem tại [FEATURE_AI_YIELD_AND_RECOMMENDATION.md](../FEATURE_AI_YIELD_AND_RECOMMENDATION.md).
